# flet-android-notifications

Native Android notifications for Flet: scheduling, action buttons, inline replies,
progress, styles, and foreground notifications.

```bash
pip install flet-android-notifications
```

Requires Python 3.11+, Flet 0.82+, and an Android APK.
Since 0.12.0, the manifest patcher requires explicit foreground-service options;
existing service declarations remain unchanged when options are omitted.

[Setup and examples](https://github.com/alex-stoica/flet-android-notifications#readme).
